# MicroSlide用户配置文件说明

## 配置文件示例：

```ini
[SystemConfiguration]
Version=1.0
Clarity=30000
FilePath=E:/image
Similarity=60
Area=40
RectX=300
RectY=300
ShowModelDebugInfo=0
ShowFPGADebugInfo=0
ShowSaveImageDebugInfo=0
SaveAllImages=1
InferenceVideoResult=0
ShowMagDetInfo=0
```



## 配置文件说明：

`[SystemConfiguration]`为节(Section)名称，表示以下键值对为系统配置

`Version`：版本号

`Clarity`：清晰度阈值

`Similarity`：相似度阈值

`Area`：区块数量阈值

`RectX`：倍率检测方框的X坐标

`RectY`：倍率检测方框的Y坐标

`FilePath`：图片文件保存路径

`ShowModelDebugInfo`：是否打印模型推理的调试信息，1表示打印

`ShowFPGADebugInfo`：是否打印FPGA的调试信息，1表示打印

`ShowSaveImageDebugInfo`：是否打印图片保存时的调试信息，1表示打印

`SaveAllImages`：是否保存所有图片，1表示保存

`InferenceVideoResult`：是否推理视频级诊断结果，1表示推理

`ShowMagDetInfo`：是否打印倍率检测线程的调试信息，1表示打印

 

***注意：***
***每次修改完配置文件后，请务必重新启动exe程序！***
